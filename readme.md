Hi, this is a git repo for my personal Cubecoders AMP game templates. (https://cubecoders.com)

### Animal Crossing GC Multiplayer:
This one barely works and needs some elbow grease to get up and running. Runs the server from this git repo: https://github.com/vsimochi/ACGC-PC-Multiplayer/

1. The config uses a static build, so there's no actual updating unless I update this repo (or you manually upload over the initial update)
2. You must supply the ROM ISO in the rom folder.
3. You must set the starting hour of the town in the config settings for the appropriate hour when you actually start the server.
4. I've only tested this on a Debian host with containers enabled.
5. I don't know if future builds of the vibecoded app are going to change more launch flags. This was built and tested on Beta 0.4.1.
